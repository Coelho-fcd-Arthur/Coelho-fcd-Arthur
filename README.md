## 🚀 Projetos em Destaque

### **Prospecta CRM / Sistema de Gestão de Clientes** 
**Lovable (Engenharia de Prompt)**

Um sistema completo de gerenciamento de relacionamento com clientes, desenvolvido para centralizar e organizar dados históricos da operação comercial da Prospecta Cred.

**O que foi construído:**
- ✅ Interface intuitiva e responsiva para cadastro e busca de clientes
- ✅ Armazenamento persistente de dados em banco de dados MySQL
- ✅ Regras de negócio integradas (validações, filtros, relatórios básicos)
- ✅ Sistema de histórico de interações com clientes

**Tecnologias:**
- `Lovable` (geração de código assistida por IA com engenharia de prompt)

**Aprendizado aplicado:** Neste projeto, aprendi a não apenas usar IA para gerar código rapidamente, mas a **compreender a lógica subjacente**, estruturar bancos de dados de forma eficiente e traduzir requisitos de negócio em funcionalidades técnicas.
